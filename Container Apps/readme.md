# Container Apps

MCP servers hosted on Azure Container Apps, plus the template they're built from.

| Folder | What it is |
|--------|------------|
| [MCP Container App Template](./MCP%20Container%20App%20Template/readme.md) | A starting point for your own MCP server: ASP.NET Core and the official MCP C# SDK, Microsoft Entra sign-in, rate limiting, health probes, Bicep, and a one-command deploy |
| [Salesforce MCP Server](./Salesforce%20MCP%20Server/readme.md) | An MCP server for Salesforce that calls the Salesforce REST API directly and does not use the Salesforce-hosted MCP servers. Read tools by default, with optional create, update, and delete tools |

Start with the template to build a server for a different system. Start with the Salesforce server to connect Salesforce to Copilot Studio or another MCP client.
